# SlowLang

Slow Lang is the Slowest Programming language to ever exist.

## Why?
this was just a challange. there were some rules to this challange.

### Rules
        - no loops
        - a function should do something. it does not matter how slow it is.

### How It Was Made Possible?
i used python3 and made requests to myself which made a lot of things complicated. 

## Key Features
        - hello world takes 20 minutes to execute
        - brainfuck like syntax
        - ! do not run this in a old computer
